# PlantColor 植物彩雅

一个展示植物色彩的 iOS App：32 种植物色，带桌面小组件。

> 526 种传统色的数据、导入和相关界面代码都保留在项目里，但目前在界面上整体关闭（不显示切换、不参与搜索、推荐和小组件）。把 `FeatureFlags.traditionalColorsEnabled` 改成 `true` 即可恢复。

## 功能

- **两套色彩**：植物色（有植物介绍、配图、诗词）与传统色（有由来、工艺、象征、诗词等，部分颜色有补充内容）。
- **首页浏览**：整屏色块，植物图案居中完整显示，上下滑动换颜色，背景色在相邻颜色之间连续过渡。顶部左右是设置和搜索；底部是收藏、简介（半屏简介，可进入完整详情）、分享。可自动 / 随机切换，间隔可选 5 / 10 / 30 秒。
- **浏览偏好**：可选择打开时恢复上次浏览或从第一张开始；植物色、传统色分别记住所在的颜色 ID，随机排序后也能按 ID 恢复。触感反馈可统一关闭，偏好保存在本机。
- **详情页**：收藏、分享海报、点击 HEX / RGB / CMYK 即可复制，底部有"配色推荐"（相近色、跨类对照、互补色、邻近色）。
- **搜索与筛选**：边输入边搜索（名称、拼音、科属、HEX，不区分大小写），可按来源（植物 / 传统）和色系筛选，列表与网格互相切换时保留条件。
- **色卡快捷操作**：在列表或网格中长按颜色，可复制 HEX、收藏或取消收藏；VoiceOver 也可通过“操作”执行这些功能。网格根据窗口宽度调整列数，拖动列表会收起键盘。首页菜单具有本地化的按钮名称，支持辅助功能激活。
- **收藏列表**：独立的色块、色名与 HEX 列表，显示实际收藏数量。可点击查看详情、使用原生编辑模式或滑动取消收藏；取消收藏只改变收藏标记，并同步刷新小组件来源列表。从详情返回时刷新收藏状态，空列表会退出编辑模式，首页收藏按钮也随真实状态更新。列表与标题支持系统文字大小及浅深色。收藏页、外观选项与色彩详情的返回按钮适配新系统的辅助功能遍历，详情收藏/分享控件提供明确名称，编辑时保留 UIKit 原生删除控件。
- **分享色卡**：植物色、传统色都可选择原色卡片、纯色、含简介三种样式，独立开关 HEX 色值。使用原始植物素材和真实简介，预览与导出共用绘制逻辑，固定输出 966 × 1278 图片；通过系统分享或保存到相册，iPad 分享提供弹窗锚点。辅助控件适配浅深色与系统文字大小，旋转和较小窗口可滚动操作。
- **小组件**：小、中、大三种尺寸；可选轮播"全部 / 仅植物色 / 仅传统色 / 仅收藏"，可设刷新频率、显示色值、自定义文字；点击小组件直达对应颜色的详情页。
- **小组件配置与预览**：设置中的独立入口复用真实小组件视图、原始素材和共享轮播数据；可比较原色与系统着色示意，调整来源、图案、色值、文字和频率，并打开预览颜色。预览不会推进轮播或更改系统着色，实际主屏幕色调与刷新时机由系统决定。
- **多语言**：简体中文、繁体中文、英文、日文、韩文（传统色的补充文字目前只有中文）。
- **系统辅助功能**：降低透明度时，首页分段浮层使用适配浅深色的实色背景；减少动态效果时，关闭首页纵横分页回弹、自动翻页动画、分段滑动及 Hero 几何转场。两项设置在系统中修改后即时生效，原始色值和植物插画保持不变。
- **设置与外观**：浏览、显示与辅助功能放在设置页前部，自动换色的间隔和随机顺序收进详情页；显示当前偏好、语言、小组件来源与实际应用版本。支持浅色、深色、跟随系统，辅助页面的原生设置行和选项行支持系统文字大小。降低透明度、减少动态效果继续跟随 iOS，设置页提供真实的系统调整路径。

## 开发环境

- Xcode 16 及以上（建议使用支持发布的正式版），Swift 5，最低支持 iOS 15
- CocoaPods

```bash
pod install
open PlantColor.xcworkspace
```

## 应用图标

- `assets/icon/plantcolor-icon-{light,dark}-1254.png` 是已确认的 1254 × 1254 PNG 母图，原样保留，不放大、不裁切、不重新生成画面。
- `AppIcon.appiconset` 使用 1024 × 1024 的 Any / Dark 主图。Xcode 从主图生成 iPhone、iPad、主屏幕、搜索、设置与通知等所需资源；App Store 使用 Any 主图。系统负责圆角遮罩。
- 支持图标外观的新系统按主屏幕外观选择深浅色；较旧系统使用 Any 图标。主屏幕图标外观与 App 内设置的主题是两套系统机制。
- 应用内 `appIcon` 图片资源保留母图的完整 1254px 分辨率，并配置 Dark 外观。Widget 使用宿主 App 的图标。

重新生成资源（需要 Pillow）：

```bash
python3 -m pip install Pillow
python3 scripts/generate_icons.py
```

脚本只从原始母图进行一次 Lanczos 缩小，以无损 PNG 保存。上传 App Store 前，在主 App 和 Widget target 中统一提高 Version / Build；主 App 的 Info.plist 已绑定工程的版本设置。更新已上架应用仍需 Archive、上传新构建，并在现有 App Store Connect 记录中提交新版本审核。

## 数据文件

| 文件 | 内容 |
| --- | --- |
| `PlantColor/Resources/PlantColor.json` | 32 种植物色 |
| `PlantColor/Resources/chinese_traditional_colors.json` | 526 种传统色 |

- 数据文件改动后，App 下次启动会自动重新导入（根据文件内容判断，不用手动升版本号），用户的收藏会保留。
- 传统色数据用脚本整理，**不要手工改 JSON 里的 RGB**：

```bash
python3 scripts/build_traditional_colors.py
```

  脚本会以 HEX 为准重新计算 RGB、修正已确认的错别字，并把脚本里 `NOTES` 的补充内容（由来、工艺、象征、诗词）写进 JSON。想给某个颜色补文字，改 `NOTES` 后重新运行即可。没有补充内容的颜色，App 会根据色值自动生成"色彩概述"和"色彩辨析"。

## 小组件与 App 的数据通道

- 两者通过 App Group `group.com.anyujia.PlantColor` 共享数据，名字必须与两个 target 的 entitlements 一致（代码里在 `WidgetCenter.swift`）。
- App 把"小组件要轮播的颜色列表"写进共享空间，小组件只负责按顺序读取并展示；收藏变化、切换来源时 App 会重新生成列表。
- 点击小组件会打开 `plantcolor://color/<plant|traditional>/<id>`。

## 调试

调试版启动时会运行一组自检（数据格式、HEX 与 RGB 是否一致、色值换算、小组件数据等），结果写在 Xcode 控制台，搜索"自检"即可。
